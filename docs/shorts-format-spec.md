# Shorts format spec — Edlintics (locked)

The repeatable recipe for every short. Reference model: **@accounting_stuff** (calm, graphic-led,
teaching) — borrow the *format*, not the hype. Our difference: the graphic shows the **real numbers
being worked**, not an abstract diagram. That's the moat.

## The frame
Full-frame **you** against a backdrop, a **graphic slide overlaid in the top ~40%**, **animated
captions** low-centre, the occasional small icon overlay. No green screen, no face-masking — you're
just filmed against a nice wall with the graphic composited on top in edit.

```
┌──────────────────────┐
│  ┌────────────────┐  │  ← top graphic (the REAL solve:
│  │  cash-flow      │  │     numbers, running total — not a
│  │  700 ← total    │  │     pretty diagram)
│  └────────────────┘  │
│                      │
│       YOU            │  ← full-frame, waist-up, eyes to lens
│   (real backdrop)    │
│                      │
│    BOLD CAPTION      │  ← animated word-by-word, blue highlight
└──────────────────────┘
```

## Your setup (film day)
- **Backdrop:** a clean, decently textured wall in a brand-ish tone (blue/neutral). His is purple —
  ours leans blue. Avoid clutter behind you.
- **Light:** soft and even — a window to your side, or one cheap softbox/ring light. No harsh shadows.
- **Camera:** phone at **eye level**, you waist-up, **leave the top-left ~40% of frame clear** for the
  graphic. Look at the lens, not the screen.
- **Audio (non-negotiable):** a **lav mic** (~€25–50). Clean sound is what separates "real channel"
  from "phone clip."

## The rules
- **Graphic = real numbers.** Every top-slide shows the actual problem being solved. I build these in
  Canva, on-brand. Never an abstract concept diagram — that's accounting_stuff's lane, not ours.
- **Length:** **start 60–90s.** One concept, tight, no filler → high completion → algorithm pushes it.
  Grow into 2–3 min later once watch-time is proven. Concept dictates the exact length.
- **Energy:** calm, confident tutor. Reassurance, not hype.
- **Captions:** bold, animated word-by-word (CapCut auto-captions), key words highlighted brand-blue.

## The 5-beat structure (every script follows this)
1. **Hook** (0–6s) — the surprising/exam-painful line, on screen immediately.
2. **Setup** (6–18s) — the problem + the given numbers appear in the top graphic.
3. **Solve** (18–55s) — work the real numbers; each line highlights as you say it; total animates.
4. **The trap** (55–68s) — "here's where marks disappear."
5. **Answer + takeaway** (68–85s) — the result + one line they'll remember. Soft CTA only.

## Production flow
You film the talking take (one continuous take, the graphic beats prepped). → I overlay the graphic
slide + animated captions + icons in CapCut from the template → you spot-check → schedule. The same
take can also feed the YouTube long-form (full worked-example) when we want both.
