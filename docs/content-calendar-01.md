# First content calendar — filming sprint (Jun–Jul 2026)

Format: **Worked Example**. Production model: **film one solve per topic, cut into many.**
Goal of this sprint: build a back-catalogue now so it is ranking before the October exam panic.

## How one shoot works
- Prep the problem (the numbers) before you hit record.
- **One take**, screen recording of the spreadsheet + clean mic. Webcam optional; the screen is the star.
- ~8–12 min raw: hit the hook in the first line, the "where everyone goes wrong" beat in the middle,
  the answer + one takeaway at the end. Do not restart for small stumbles.
- Output per shoot:
  - **1 YouTube video** — trimmed to 5–8 min, titled by concept.
  - **2 short cuts** — Short A = the hook + the trap; Short B = one tricky sub-step. For TikTok + Reels + Shorts.

## The 4-week schedule
The principle: **film ahead, publish steadily.** Build a buffer first so you never run dry, then
release one worked example a week with its shorts spread across the week.

| Week (Mon) | Film | Publish |
|---|---|---|
| **Jun 8** | Set up accounts (TikTok/YouTube/IG) · film #1, #2 | nothing yet — building the buffer |
| **Jun 15** | Film #3, #4 | **#1** YouTube (Mon) + Short A (Wed) + Short B (Fri) |
| **Jun 22** | Film #5 | **#2** YouTube + its two shorts |
| **Jun 29** | Film #6 + start the next batch | **#3** YouTube + its two shorts |
| **Jul 6 onward** | keep one shoot ahead | one worked example + shorts per week |

By the end of July you have ~6 worked examples live and a buffer in the can — exactly the ranked
catalogue we want sitting there when midterms hit in October.

## Cadence reality
One worked example a week (≈3 posts: 1 YouTube + 2 shorts) is the target for a single operator. If a
week is heavy, drop to one shoot every two weeks — the buffer absorbs it. The non-negotiable is
**keep filming ahead**; do not let publishing catch up to production.
