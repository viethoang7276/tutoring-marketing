# Edlintics — getting-started checklist

The path from where we are now to live content. (Posted to Slack 2026-06-06.)

## 1. Accounts
You create these — I prep and guide; I cannot make accounts or log in for you.
- [ ] TikTok `@edlintics` — Education category + bio
- [ ] YouTube `@edlintics` — set the handle carefully, add channel description
- [ ] Instagram `@edlintics` — Education category + bio
- [ ] Same wordmark profile image on all three
- [ ] `edlintics.com` in every bio

## 2. Confirm the plan
- [ ] Channels: YouTube primary, TikTok + Reels as the net
- [ ] Stay topic-led — concept in the headline, never a university
- [ ] Cadence — the honest number of pieces a week you can sustain
- [ ] Lead concepts: cash-flow statement + T-accounts
- [ ] Filming setup ready: screen capture + clean audio

## 3. First content (the long pole — start this week)
- [ ] Script + film worked example #1: cash-flow statement (you solve it on screen, calm narration)
- [ ] Edit: one YouTube cut + 2–3 short hooks for TikTok / Reels
- [ ] Publish on YouTube, cross-post to TikTok + Reels with the hashtag stack
- [ ] Repeat for #2: T-accounts

## 4. Automation (optional, on your word)
- [ ] Monday auto-report to Slack
- [ ] Two-way Slack loop: your reply in the thread triggers a working session

_Why this order: accounts and filming have the longest lead time, and content needs weeks to rank
before the October exam panic. Everything else moves fast once those are going._
