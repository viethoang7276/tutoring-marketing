# Edlintics brand graphics catalog

> Repo copy of the project doc `claude/brand-graphics.md` (22 Oct 2026). Add new rows to both copies.

The Canva folder **Edlintics · Brand graphics** (FAHYugebSqU) holds the generated, on-brand graphics. Before you generate a new graphic, search this table by concept and tags and reuse a match. After you generate one, file it in the folder and add a row here.

**Style:** flat vector look, white background, blue #2960C7, navy #0D1523, light blue #C9D8F5 and gold #C2922F accents, no text.

**Sizes:**
- Illustrations: 16:9, placed at 640×360 on idea pages.
- Icons: square, for the small frames.
